Using this store

The storefront provides text labels, keyboard-operable controls, focus indicators and product descriptions. Feedback

Include the affected page and the type of device or browser when helpful. Please share only the information needed to explain the issue. We will review the report and work to provide a practical way to complete the task. This statement does not claim certification or conformance testing against a particular accessibility standard.
